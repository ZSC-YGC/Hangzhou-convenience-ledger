# 杭城便民生活台账
> 一个纯前端浏览器本地台账工具，记账、出行记录、待办备忘录。**所有数据存储在浏览器 LocalStorage，不上传服务器**。

[![GitHub Pages](https://img.shields.io/badge/GitHub‑Pages-Online-green)](https://zsc‑ygc.github.io/Hangzhou‑convenience‑ledger/)
> 在线访问地址：https://zsc‑ygc.github.io/Hangzhou‑convenience‑ledger/

## 📖 项目简介
杭城便民生活台账，面向杭州本地生活设计的单页Web应用。无需后端、无需数据库，全部运行于浏览器。
- ✅ 收支账单管理 + 可视化图表统计
- ✅ 杭州地铁站点出行记录
- ✅ 待办备忘录
- ✅ 首页总览：实时时间、农历、杭州天气、浙A限行提示、季节生活提示
- ✅ 数据全部保存在浏览器本地，隐私安全

## 📋 功能说明
### 🏠 首页总览
首页展示生活信息卡片：
1. **今日时间信息**：公历日期、星期、时分秒实时刷新，附带农历干支信息。
2. **杭州实时天气**：调用开放气象API，展示温度、湿度、天气状况、风速，每30分钟自动更新。
3. **台风速报**：提供中央气象台台风页面跳转链接。
4. **浙A限行提示**：自动根据星期计算杭州工作日限行尾号，周末自动提示不限行。
5. **季节提示**：根据月份给出对应的生活穿衣出行提示。

页面底部可以打开【关于本项目】弹窗，查看项目版本、仓库地址。

### 💰 收支账单
1. 切换单选框选择「收入 / 支出」，下拉框会自动切换对应的分类选项。
    - 收入：工资、奖金、其他
    - 支出：交通、餐饮、娱乐、健康、教育、其他
2. 填写金额、选择日期、填写备注，点击**添加账单**。
3. 图表展示：
    - 柱状图：总收入、总支出对比
    - 饼图：支出分类占比、收入分类占比
4. 下方列表展示全部账单记录，支持单条删除。
> 数据全部保存在浏览器本地存储。

### 🚇 通勤统计（出行记录）
1. 出行方式可选：公交、地铁、自驾、步行、其他。
2. 当选择**地铁**时，站点下拉框激活，可以选择杭州地铁全部线路站点，支持搜索站名快速筛选。
3. 填写出行日期、时间、备注，点击记录出行。
4. 列表展示全部出行记录，支持删除记录。

### 📝 待办备忘录
1. 输入待办内容，点击添加待办。
2. 勾选复选框标记任务完成，自动添加删除线。
3. 列表展示创建时间，支持删除待办。

## 📦 技术栈
- HTML5 + CSS3 + JavaScript（原生JS）
- jQuery 3.7.1
- Select2 4.1.0‑rc.0：下拉搜索选择器（地铁站点、账单分类）
- Chart.js 4.4.8：图表绘制（账单柱状图、饼图）
- lunar‑javascript：农历日期转换
- Open‑Meteo API：杭州实时天气获取
- LocalStorage：浏览器本地持久化存储所有业务数据

## ⚠️ 重要注意事项
1. **数据存储位置**
所有账单、出行、待办保存在浏览器 `LocalStorage`。
- 清除浏览器缓存、无痕模式关闭、重置浏览器会丢失数据。
- 更换浏览器、更换电脑，数据不会自动迁移。

2. GitHub Pages 网络问题
国内访问 GitHub Pages CDN速度较慢，背景图片可能延迟加载，属于网络环境问题。

3. 天气接口
天气依赖第三方开放API，网络异常会显示获取失败，刷新页面即可重试。

4. 限行规则
程序内置杭州工作日限行规则，节假日调休不会自动识别，遇到节假日请以官方通告为准。
